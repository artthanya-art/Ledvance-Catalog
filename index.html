พื้นที่ฐานคำนวณจาก ปริมาตรถัง ÷ ความลึกน้ำสมมติทั่วไปของแต่ละประเภทถัง (EQ/AS ~3.5-4.5m, UASB ~5m, MBBR/MBR ~4-4.5m, ถังพักตะกอน/reject ~3m) ส่วนถังตกตะกอน/กรองทรายคำนวณจากพื้นที่ผิวโดยตรงอยู่แล้ว (ไม่ต้องหารความลึก)

ตัวคูณพื้นที่รวม (Spacing Factor) คูณพื้นที่ฐานรวมเพื่อประมาณพื้นที่ทั้งไซต์ที่ต้องใช้จริง ครอบคลุมทางเดิน/ถนนเข้าซ่อมบำรุง/พื้นที่วางอุปกรณ์เสริม (blower, ตู้ควบคุม) — ค่าเริ่มต้น 2.5 เท่า เป็นค่ากลางสำหรับผังแบบเรียงเส้นตรง (linear layout) ทั่วไป ถ้าผังซับซ้อน/มีอาคารคลุมควรเพิ่มเป็น 3-4 เท่า

ความกว้างขั้นต่ำ ประมาณจาก √(พื้นที่ถังที่ใหญ่ที่สุด) + ระยะเผื่อทางเดินสองด้าน แล้วเทียบกับความกว้างขั้นต่ำสำหรับรถเข้าซ่อมบำรุง/ดูดตะกอน (6 เมตร) เลือกค่าที่มากกว่า — เป็นค่าประมาณคร่าวๆ ระดับแนวคิดเท่านั้น ไม่ใช่ผังจริง ควรให้วิศวกรจัดผังไซต์ (site layout) จริงก่อนตัดสินใจ

กำลังไฟฟ้าต่อเครื่อง (kW) ประมาณจากภาระไฟฟ้ารวมที่ติดตั้ง = ค่าไฟเฉลี่ยต่อปี (จากหมวด OPEX) ÷ 8,760 ชม. × Diversity Factor 1.8 (เผื่อ peak/มอเตอร์สำรอง) แล้วกระจายตามสัดส่วนราคาแต่ละเครื่อง (เครื่องแพงกว่า = กำลังไฟฟ้าสูงกว่าโดยประมาณ) จากนั้นคำนวณกระแส I = P/(√3×380V×0.85×0.9) เพื่อเลือกขนาดสาย+ราคาสายไฟที่สเกลตามกระแส และราคาตู้ Starter/VFD สเกลตาม kW

ระยะสายไฟประมาณจากขนาดพื้นที่ไซต์รวม (หมวด 06) หารด้วยจำนวนเครื่องจักร บวกระยะเผื่อ เนื่องจากยังไม่รู้ตำแหน่งตู้ MCC จริง

ระดับการควบคุม 3 แบบ — ระบบเลือกให้อัตโนมัติตาม Q แต่เปลี่ยนเองได้ (เช่น ระบบเล็กแต่ต้องรายงานหน่วยงานกำกับดูแล ควรเลือก SCADA):
  • พื้นฐาน (Q<100): Float Switch กลไกล้วน + ตู้ Timer/Relay ไม่มี PLC — เหมาะระบบเล็กมีคนดูแลเป็นระยะ
  • PLC พื้นฐาน (Q 100-1,000): Flow Meter + Level Sensor + PLC/HMI ในพื้นที่ ไม่มี pH/DO/Chlorine online และไม่มีเฝ้าระยะไกล
  • PLC+SCADA เต็มรูปแบบ (Q>1,000): ครบทุกเครื่องมือวัด + เฝ้าระยะไกล/บันทึกข้อมูล เหมาะกับระบบไม่มีคนเฝ้าตลอดหรือต้องรายงานผลออนไลน์

ค่าไฟส่องสว่าง/ปลั๊กทั่วไป คิดจากพื้นที่ไซต์รวมที่ประมาณไว้ในหมวด 06 (คงที่ทุกระดับการควบคุม)

ราคาก่อสร้าง/อุปกรณ์เป็นประมาณการอย่างหยาบจากค่าเฉลี่ยตลาดทั่วไป ราคาอุปกรณ์ถือว่ารวมค่าขนส่งมาถึงในประเทศแล้ว (เพราะเป็นราคาตลาดที่ซื้อขายจริงในไทย ไม่ใช่ราคาหน้าโรงงานต่างประเทศ) จึงไม่มีการบวกค่าขนส่งซ้ำอีกชั้น

ค่าท่อ+วาล์ว คำนวณแบบละเอียดจากขนาดท่อจริง (สูตรความต่อเนื่อง D=√(4Q/πv)) + ความยาวประมาณจากผังไซต์ + จำนวนวาล์วต่อจุดต่อ (ดูรายละเอียดในตาราง Piping BOQ พร้อมหมายเหตุสูตรด้านล่างของตารางนั้น) ไม่ใช่ % คงที่แบบเดิมอีกต่อไป

ค่าไฟฟ้า/ควบคุม คำนวณจากภาระไฟฟ้ารวมที่ติดตั้งจริง + จำนวนเครื่องมือวัดตามระดับการควบคุมที่เลือก (พื้นฐาน/PLC พื้นฐาน/SCADA เต็มรูปแบบ) ไม่ใช่ % คงที่เช่นกัน (ดูรายละเอียดในตาราง Electrical BOQ ด้านล่าง)

ต้นทุนระดับโปรเจค (ออกแบบ/ใบอนุญาต/VAT/Contingency) คำนวณต่อเนื่องกันตามลำดับ: (งานโยธา+อุปกรณ์+ท่อ+ไฟฟ้า/ควบคุม) → บวกออกแบบ+ใบอนุญาต → บวก VAT → บวก Contingency เป็นขั้นสุดท้าย รายละเอียดสูตรอยู่ในเอกสารอ้างอิงสูตร

ค่าบำรุงรักษา/ปี คิดเป็น % ของราคาแต่ละรายการ (งานโยธา ~1.5%/ปี, เครื่องจักรทั่วไป ~5-6%/ปี, เมมเบรน MBR ~12%/ปี, เครื่องรีดตะกอน ~7%/ปี, ท่อ+วาล์ว ~2%/ปี, ไฟฟ้า/ควบคุม ~4%/ปี) ครอบคลุมเฉพาะอะไหล่/ซ่อมบำรุงเครื่องจักรเท่านั้น — ค่าไฟ/สารเคมี/แรงงาน ดูเพิ่มเติมด้านล่าง

08

ค่าดำเนินการต่อปี (OPEX)

รวม OPEX โดยประมาณต่อปี ฿0/ปี
ทำไมไม่รวม CAPEX กับ OPEX เป็นตัวเลขเดียว: CAPEX (ราคาก่อสร้าง/อุปกรณ์) เป็นเงินลงทุนครั้งเดียวตอนเริ่มโปรเจค ส่วน OPEX เป็นค่าใช้จ่ายที่เกิดซ้ำทุกปีตลอดอายุการใช้งานระบบ การบวกรวมกันเป็นก้อนเดียวจะทำให้ตัวเลขสื่อความหมายผิด (เหมือนเอาค่าใช้จ่าย 1 ครั้ง ไปบวกกับค่าใช้จ่ายรายปีคูณ 1 ปี) — ในการประเมินความคุ้มค่าโปรเจคจริง ควรใช้ OPEX ต่อปีคูณอายุการใช้งานระบบ (เช่น 15-20 ปี) แล้วคิดมูลค่าปัจจุบัน (NPV) แยกจาก CAPEX
09

NPV / มูลค่าปัจจุบันของค่าใช้จ่ายตลอดโครงการ

Total Cost of Ownership (TCO / NPV รวม) ฿0
สูตร: PV(OPEX) = OPEX ต่อปี × [1 − (1+r)⁻ⁿ] / r โดย n = จำนวนปี, r = อัตราคิดลด (แปลงเป็นทศนิยม)
TCO = CAPEX + PV(OPEX)

สมมติฐาน: OPEX คงที่ทุกปีตลอดโครงการ (ยังไม่ปรับตามเงินเฟ้อ/ค่าไฟที่อาจเพิ่มขึ้นในอนาคต) และไม่ได้หักค่าซาก (salvage value) หรือคิดค่าเปลี่ยนอุปกรณ์ใหญ่ระหว่างทาง (เช่น เปลี่ยนเมมเบรน MBR รอบใหญ่ตอนปีที่ 8-10) — ตัวเลขนี้เหมาะสำหรับเปรียบเทียบทางเลือกระบบเบื้องต้นเท่านั้น
